The Integrations Hub tab is where you connect AgyDesk to the external services your automation workflows use — CRMs, spreadsheets, communication tools, AI media engines, and cloud storage. Once connected, your daemon workers can push extracted data directly to HubSpot, post Slack alerts, trigger HeyGen video renders, save exports to S3, and more — without any manual data transfer.

## Available Integrations

AgyDesk provides 10 native connectors, organized across five categories:

| Service | Category | Auth Method |
|---------|----------|-------------|
| HubSpot | CRM | OAuth 2.0 |
| Salesforce | CRM | OAuth 2.0 |
| Google Sheets | Data | OAuth 2.0 |
| Airtable | Data | API Key |
| Zapier / Make | Automation | Webhook URL |
| Slack | Notifications | Webhook URL |
| Telegram | Notifications | Bot Token + Chat ID |
| HeyGen | AI Video | API Key |
| ElevenLabs | AI Voice | API Key |
| GCS / AWS S3 | Storage | API Key |

## Connecting an Integration

<Steps>
  <Step title="Open the Integrations Hub tab">
    In your dashboard, click the **Integrations Hub** tab in the Workstation Cockpit navigation bar.
  </Step>
  <Step title="Find the service">
    Browse the integration grid or filter by category using the pill buttons at the top: **CRM**, **Data Tables**, **Notifications**, **AI Media**, or **Storage**.
  </Step>
  <Step title="Click Connect">
    Click the **Connect** button on the service card. For OAuth services (HubSpot, Salesforce, Google Sheets), you are redirected to the provider's authorization page. For API key services (Airtable, HeyGen, ElevenLabs, S3, GCS), a credentials form appears inline.
  </Step>
  <Step title="Complete authentication">
    - **OAuth**: Complete the provider's authorization flow and grant the requested permissions. You are redirected back to AgyDesk automatically.
    - **API Key**: Paste your API key, secret, or token into the form fields. For Telegram, enter both the Bot Token and the target Chat ID.
    - **Webhook URL**: Paste the inbound webhook URL generated by Zapier, Make, or Slack.
  </Step>
  <Step title="Save and verify">
    Click **Save**. The status badge on the integration card changes from **OFFLINE** to **ACTIVE** with a pulsing green indicator. AgyDesk performs a test ping to confirm the connection is live.
  </Step>
</Steps>

## Using Integrations in Workers

Once connected, reference integrations in your daemon workers using the environment variables AgyDesk injects into the pod. For example, to push a Slack notification from a generated worker:

```typescript
// Slack webhook is injected as SLACK_WEBHOOK_URL
const slackWebhook = process.env.SLACK_WEBHOOK_URL;

await fetch(slackWebhook, {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    text: `✅ Scrape complete: extracted ${results.length} records`,
  }),
});
```

All connected integration credentials are securely stored and automatically available as environment variables inside your pod at runtime.
