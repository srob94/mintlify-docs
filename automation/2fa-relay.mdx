When an automation worker encounters a two-factor authentication prompt, it cannot proceed without human input — and simply timing out would break the entire workflow. AgyDesk's 2FA Relay system bridges this gap elegantly: the bot pauses and sends you a notification via Slack or Telegram, you provide the code through the dashboard or directly in the notification channel, and the bot retrieves the resolution and continues exactly where it left off. Your automation stays uninterrupted without ever embedding sensitive codes in worker scripts.

## How It Works

The relay is a lightweight challenge-response loop built on two API endpoints. No long-running WebSocket connections or polling servers are needed on your side — just two HTTP calls from inside your worker.

<Steps>
  <Step title="Worker detects a 2FA screen">
    Your worker identifies the 2FA prompt — by checking for a specific input field, page title, or URL pattern — and calls `POST /api/agent/relay-2fa` with `action: "create_challenge"`. AgyDesk stores the challenge keyed by your pod ID and marks it `pending`.
  </Step>
  <Step title="You receive a notification">
    AgyDesk immediately sends a notification to every channel you have configured in the Integrations Hub — Slack, Telegram, or both. The alert includes your pod ID, the service that triggered the challenge, and a direct link to your AgyDesk dashboard.
  </Step>
  <Step title="You provide the 2FA code">
    Open the AgyDesk dashboard and enter the code in the **2FA Relay** panel, or use the link in your notification to go there directly. AgyDesk updates the challenge with the code you provide.
  </Step>
  <Step title="AgyDesk stores the resolution">
    The challenge status flips from `pending` to `resolved` and the `resolvedCode` field is populated.
  </Step>
  <Step title="Worker retrieves the code">
    While waiting, your worker polls `GET /api/agent/relay-2fa?podId=<your-pod-id>` every 5 seconds. Once the challenge status is `resolved`, the response includes `challenge.resolvedCode`.
  </Step>
  <Step title="Worker enters the code and continues">
    The worker types the retrieved code into the 2FA input field, submits the form, and continues the automation from where it paused.
  </Step>
</Steps>

## Setting Up Notifications

Configure at least one notification channel so you receive 2FA alerts in real time. You can add both Slack and Telegram for redundancy.

<Steps>
  <Step title="Open the Integrations Hub">
    In your AgyDesk dashboard, click the **Integrations Hub** tab.
  </Step>
  <Step title="Connect Slack">
    Under **Slack**, paste your Incoming Webhook URL (create one at api.slack.com/apps → Incoming Webhooks). AgyDesk sends a test message to confirm the connection.
  </Step>
  <Step title="Connect Telegram">
    Under **Telegram**, enter your Telegram Bot Token and the Chat ID for the channel or group where you want alerts delivered. See [Notifications Setup](/integrations/notifications) for step-by-step instructions on creating a Telegram bot.
  </Step>
</Steps>

## API Reference for Workers

Your worker interacts with the relay through two endpoints.

### Create a Challenge

Call this endpoint when your worker detects a 2FA prompt. The pod ID should be your unique pod identifier (visible in **Cloud Settings** in the dashboard).

<ParamField body="podId" type="string" required>
  Your cloud pod's unique identifier, e.g. `my-pod`.
</ParamField>
<ParamField body="action" type="string" required>
  Must be `"create_challenge"`.
</ParamField>
<ParamField body="type" type="string">
  The type of 2FA challenge, e.g. `"sms_2fa"` or `"totp"`. Defaults to `"sms_2fa"`.
</ParamField>
<ParamField body="service" type="string">
  Human-readable name of the service that triggered the challenge, e.g. `"linkedin"` or `"gmail"`. Included in the notification message.
</ParamField>
<ParamField body="message" type="string">
  Optional custom message to include in the notification, e.g. `"SMS code required for LinkedIn login"`.
</ParamField>
<ParamField body="screenshotUrl" type="string">
  Optional URL of a screenshot of the 2FA screen, attached to the notification for context.
</ParamField>

```bash
curl -X POST https://agydesk.com/api/agent/relay-2fa \
  -H "Content-Type: application/json" \
  -d '{
    "podId": "my-pod",
    "action": "create_challenge",
    "service": "linkedin",
    "message": "SMS 2FA code required to continue"
  }'
```

```json
{
  "success": true,
  "status": "challenge_created",
  "podId": "my-pod"
}
```

### Resolve a Challenge

Call this endpoint to supply the 2FA code once you have it — for example, from a custom integration or script. The dashboard handles this for you automatically when you enter a code in the **2FA Relay** panel.

<ParamField body="podId" type="string" required>
  The pod ID of the challenge to resolve.
</ParamField>
<ParamField body="action" type="string" required>
  Must be `"resolve_challenge"`.
</ParamField>
<ParamField body="code" type="string" required>
  The 2FA code to deliver to the waiting worker.
</ParamField>

```bash
curl -X POST https://agydesk.com/api/agent/relay-2fa \
  -H "Content-Type: application/json" \
  -d '{
    "podId": "my-pod",
    "action": "resolve_challenge",
    "code": "847291"
  }'
```

```json
{
  "success": true,
  "status": "resolved",
  "podId": "my-pod",
  "code": "847291"
}
```

### Poll for Resolution

Poll this endpoint from inside your worker until the challenge is resolved. Returns `null` for `challenge` if no active challenge exists for the given pod ID.

```bash
GET https://agydesk.com/api/agent/relay-2fa?podId=my-pod
```

```json
{
  "challenge": {
    "podId": "my-pod",
    "type": "sms_2fa",
    "message": "SMS 2FA code required to continue",
    "timestamp": "2025-03-15T14:32:07.421Z",
    "status": "resolved",
    "resolvedCode": "847291"
  }
}
```

## In-Worker Code Example

Integrate the relay into any daemon worker with a detect-pause-resume pattern. Add this logic inside your `runCycle()` method wherever a 2FA screen may appear.

```typescript
const POD_ID = "my-pod"; // Replace with your actual pod ID from Cloud Settings

/** Send a CDP command (see full worker pattern in Daemon Workers guide) */
async function sendCdpCommand(wsUrl: string, method: string, params: any = {}): Promise<any> {
  // ... standard CDP WebSocket call
}

function sleep(ms: number) {
  return new Promise((resolve) => setTimeout(resolve, ms));
}

/** Check whether the current page is showing a 2FA prompt */
async function is2FAPage(wsUrl: string): Promise<boolean> {
  const result = await sendCdpCommand(wsUrl, "Runtime.evaluate", {
    expression: `!!document.querySelector('input[name="pin"], input[autocomplete="one-time-code"], #verification-code-input')`,
    returnByValue: true,
  });
  return result?.result?.value === true;
}

/** Pause the worker, send a notification, and wait for human resolution */
async function handle2FA(wsUrl: string): Promise<string> {
  console.log("🚨 [2FA Relay] 2FA screen detected — creating challenge...");

  // 1. Create the challenge — AgyDesk notifies you via Slack/Telegram
  await fetch("https://agydesk.com/api/agent/relay-2fa", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({
      podId: POD_ID,
      action: "create_challenge",
      service: "linkedin",
      message: "LinkedIn SMS verification code required",
    }),
  });

  // 2. Poll for resolution (timeout after 5 minutes)
  const timeoutAt = Date.now() + 5 * 60 * 1000;
  while (Date.now() < timeoutAt) {
    await sleep(5000);

    const res  = await fetch(`https://agydesk.com/api/agent/relay-2fa?podId=${POD_ID}`);
    const data = await res.json();

    if (data.challenge?.status === "resolved" && data.challenge.resolvedCode) {
      console.log("✅ [2FA Relay] Resolution received.");
      return data.challenge.resolvedCode;
    }

    console.log("⏳ [2FA Relay] Waiting for 2FA code...");
  }

  throw new Error("2FA relay timed out after 5 minutes — no code was provided.");
}

/** Example runCycle snippet that handles a mid-session 2FA challenge */
async function runCycle(wsUrl: string) {
  // ... navigate, log in, do work ...

  // After a login attempt, check whether 2FA appeared
  if (await is2FAPage(wsUrl)) {
    const code = await handle2FA(wsUrl);

    // Type the code into the verification input and submit
    await sendCdpCommand(wsUrl, "Runtime.evaluate", {
      expression: `
        (() => {
          const input = document.querySelector('input[autocomplete="one-time-code"], #verification-code-input');
          if (input) {
            input.value = "${code}";
            input.dispatchEvent(new Event("input", { bubbles: true }));
            const form = input.closest("form");
            if (form) form.submit();
          }
        })()
      `,
    });

    await sleep(3000); // Wait for post-2FA redirect
  }

  // ... continue automation ...
}
```

<Tip>
  Configure **both Slack and Telegram** in the Integrations Hub. That way, if you miss the Slack notification while away from your desk, the Telegram mobile push ensures you never miss a 2FA alert — and your automation is never stuck waiting indefinitely.
</Tip>
